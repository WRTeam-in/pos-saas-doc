General settings

Platform-wide settings live in one place, with a menu on the left. Settings are saved in the database and take effect at once.

Where to find it: sidebar, Settings. Needs settings.manage.

The settings menu groups pages like this:

GroupPages
GeneralPlatform, Appearance, New business defaults
Sign-up and billingSign-up, Billing, Payments
MessagingSystem email, Email templates
Security and systemSecurity, Legal pages, Languages, Backups, File storage, System updates, System

Changes that alter a value are written to the Audit log as "Settings updated" (secrets are masked).

Platform​

FieldWhat it does
Platform nameShown in the panel, emails and the authenticator app. Empty uses the name from the server configuration
Support emailReceives new support requests. Empty means every admin is emailed
Company name, Company addressYour company details
Email a weekly summary to platform adminsSent Mondays at 08:00. Needs the scheduler cron job
Logo (light theme), Logo (dark theme)Wide logo with your name, for the sidebar, sign-in pages and website header. The dark one falls back to the light one. PNG, JPG or WebP, up to 1 MB. Empty space around the logo is trimmed and a very large logo is scaled down when you upload it, so there is no need to crop or resize it first
Short logo (light theme), Short logo (dark theme)Square icon for the collapsed sidebar. PNG, JPG or WebP, up to 1 MB. Trimmed and scaled the same way
Login backgroundShown behind the sign-in and sign-up pages. PNG, JPG or WebP, up to 4 MB. Large pictures are saved as a screen-sized WebP (up to 1920 px wide) so the page loads fast. With none uploaded, the built-in picture public/images/auth-bg.jpg is used (a .jpeg, .png or .webp file with the same name also works)
FaviconPNG, ICO, JPG or WebP, up to 512 KB

Appearance​

The look of the admin panel.

FieldWhat it does
Accent colourFixes the panel colour for everyone. When none is set, each admin picks a palette from the header
Text on the accent colourAuto, White or Dark. Auto picks the most readable
Default themeLight, Dark or System, until an admin chooses
FontThe font used across the panel

New business defaults​

Starting values for a business created at sign-up.

FieldWhat it does
Default currencyCurrency of new businesses
Default timezoneUsed when the visitor's browser does not report one

Sign-up​

FieldWhat it does
Allow new sign-upsWhen off, nobody can create a new business. Existing businesses are not affected
Require email verification at signupNew businesses must verify their email before they can invite team members or take online payments
Blocked email domainsOne per line, for example mailinator.com. Subdomains are blocked too
Invitations per business per hour / per dayLimits how fast a business can send team invitations (1 to 1000 per hour, 1 to 5000 per day)
Invitations per person per hour / per dayThe same limits for each person who invites

Billing​

FieldWhat it does
Grace period (days)How long a business keeps full access after a failed renewal. 0 to 60. Default 7
Trial ending reminder (days before)When the trial reminder email is sent. 1 to 14. Default 4
Renewal reminders (days before)Comma separated whole numbers from 1 to 60, for example 7, 3, 1. Up to 5 values. Only the nearest threshold is sent
Invoice number prefixLetters, numbers and dashes, up to 10 characters. Default INV-. Existing invoices keep their numbers

Reminder emails are sent by the daily job subscriptions:remind at 09:00. They go to the business owner.

System email​

The mail server used for verification, password reset, invitations and billing emails.

FieldWhat it does
Mail server, Port, Username, PasswordSMTP details. The default port is 587. Leave the server empty to use the .env mail configuration. Leave the password blank to keep the saved one
EncryptionTLS (default), SSL or None
From address, From nameThe sender shown on emails

Use Send test email to send one message to your own address with the saved settings. A server address that is private or local is refused for the test.

Security​

FieldWhat it does
Email admins about security eventsSign-in from a new address, 2FA lockouts, admins added or removed, 2FA resets
Require two-factor authentication for adminsSee Login and two-factor
Admin idle timeout (minutes)5 to 240. Default 30
Shop session lifetime (minutes)How long a business user stays signed in. 15 to 1440
Minimum password length (shop)8 to 64
Failed sign-ins before lockout (shop)3 to 20

The shop fields apply to businesses. The admin sign-in throttle and admin password rule are fixed in code.

System​

FieldWhat it does
Show a maintenance notice on every shop pageTurn on to show a notice to businesses
Notice textUp to 300 characters. Empty shows "The system is under maintenance. Some features may be unavailable."

The System health card on this page shows:

RowMeaning
SchedulerRunning, Not running (check the cron job), or No heartbeat yet. A heartbeat is written every minute; it is stale after 5 minutes without one
Queued jobs, Failed jobsCounts from the queue tables
PHP version, Framework versionWhat the server is running

If the scheduler is not running, subscriptions do not advance, reminders and backups do not run, and the weekly summary is not sent. See Cron jobs and Queue worker.
