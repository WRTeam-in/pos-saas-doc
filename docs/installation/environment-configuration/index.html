Environment configuration

The installer writes your .env file. You rarely need to touch it, but these are the values that matter. Most business settings live inside the panels, not in .env.

Where to find it: the .env file in the project root.

Key values​

VariableWhat it does
APP_NAMEThe application name. Set by the installer.
APP_URLYour site's full address, for example https://example.com.
APP_ENVproduction on a live site.
APP_DEBUGMust be false on a live site.
APP_KEYThe encryption key. Never change it on a live site.
DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORDDatabase connection.
ADMIN_DOMAINServe the Super admin panel on its own host (for example admin.example.com) instead of /admin. Leave empty to use /admin.
BACKUP_MYSQLDUMP_PATHPath to mysqldump if it is not on the PATH. Used by backups.
INSTALLER_VALIDATOR_URLPurchase code validator used by the installer. Leave the default.
DEMO_MODE, DEMO_BYPASS_EMAILS and other DEMO_* valuesFor a public demo site only. See Demo mode.
LANDING_DEMO_URLThe Live demo button's link until you save one under Website.
SESSION_DRIVER, CACHE_STORE, QUEUE_CONNECTIONDefault to database.
warning

Changing APP_KEY makes saved encrypted values unreadable, such as gateway keys and SMS secrets. Back it up.

Email​

The .env mail values default to the log mailer, which only writes emails to the log. For real email, enter your SMTP details in the Super admin panel under Settings > System email, then use Send test email. Businesses can also use their own mail account in their email settings.

After changing .env​

Clear cached configuration so the new values are read:

php artisan optimize:clear
